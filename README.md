# PhoneCraft Optimized

PhoneCraft Optimized is a Minecraft modpack designed for mobile devices, offering a collection of optimization mods to enhance performance on low-end hardware. This modpack includes essential optimization mods, quality-of-life enhancements, and popular add-ons, excluding aeronautics, ComputerCraft, and other resource-intensive mods. It is compatible with Minecraft 1.20.4 and the Fabric mod loader.

## Install

1. Install the Fabric mod loader for Minecraft 1.20.4.
2. Download the PhoneCraft Optimized modpack from the EnderDevelopment marketplace.
3. Extract the downloaded zip file into your Minecraft directory, replacing any existing files.
4. Launch Minecraft using the Fabric profile.

## Use

1. Launch Minecraft and select the Fabric profile.
2. Start a new world or load an existing one.
3. Enjoy the optimized gameplay experience on your mobile device.
